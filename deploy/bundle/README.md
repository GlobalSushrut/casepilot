Put the released Connector OS archive here before startup:

```text
deploy/bundle/connector-os.tar.gz
deploy/bundle/connector-os.tar.gz.sha256   # optional, one line: "<sha256>  connector-os.tar.gz"
```

CasePilot's setup screen installs that archive and will not open the desks without a live Connector. This directory does not contain a substitute package.
